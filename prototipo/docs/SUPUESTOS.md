# Supuestos

Decisiones tomadas ante ambigüedades del documento o del encargo. Cada una indica su origen y su efecto.

| ID | Ambigüedad | Decisión | Efecto |
|:---|:---|:---|:---|
| S-01 | El encargo pedía Alfa en JSON y Beta en XML tipo UBL; el documento y la base definen Alfa como XML del Perfil Alfa v2.1 (UBL 2.1) y Beta como texto por segmentos. | **Aceptada por el autor (2026-10-19):** se conservan los formatos del documento. Alfa: XML del Perfil Alfa v2.1, con un sobre JSON en su API REST. Beta: texto por segmentos. | El kit, las reglas D1 a D6 y el banco de 22 mutantes se reutilizan sin cambios de semántica. |
| S-02 | "Todo arranca con un comando en un solo proceso" y el plano agéntico es Python. | El perfil `local` arranca un proceso Java (integración, simuladores y gateway) y un proceso Python (plano agéntico), ambos con `scripts/run-local.ps1`. | Un comando, dos procesos; no hay forma de alojar Python dentro de la JVM sin una dependencia extra. |
| S-03 | El documento describe un microservicio por pieza; el encargo pide aplicaciones Boot delgadas. | Una biblioteca por servicio y una sola aplicación Boot (`platform-app`) que habilita servicios con `veriagent.services`. | En el perfil `full` cada contenedor corre la misma imagen con un subconjunto de servicios. También en `DESVIACIONES.md` (D-03). |
| S-04 | El documento no define el evento que dispara la recarga de mapeos. | Se añade el topic `platform.mapping.activated.v1`. | Registrado también en `DESVIACIONES.md` (D-02). |
| S-05 | El perfil Alfa v2.1 de la base pertenece a un "País Alfa" sintético; el encargo pide CO, PE y XX. | Los países determinan numeración, moneda, tipos de identificación y enrutamiento; los proveedores mantienen sus formatos y catálogos propios, y el mapeo traduce los códigos canónicos a los del proveedor. | Las fuentes normativas citadas (DIAN, SUNAT) solo se usan para catálogos públicos y numeración. |
| S-06 | No existen `data/numeracion/*.csv` en la base. | Se crea una configuración de numeración sintética por país con la estructura pedida y la fuente documentada. | Si el autor aporta esos archivos, se usan en su lugar. |
| S-07 | El escenario S5 exige incorporar un país nuevo con un proveedor nuevo. | **Decisión del autor (2026-10-19):** tercer proveedor sintético **Gamma**, con formato JSON, asociado al país sintético XX y con su propia especificación sintética en `specs/`. | El agente de mapeo propone el mapeo de Gamma desde su especificación; el kit verifica Gamma con reglas derivadas de esa especificación. |
| S-08 | El documento exige mínimo privilegio para la IA, pero no define autenticación de las APIs internas. | Tokens de demostración aleatorios por rol (`REVIEWER`, `AGENT`, `OPERATOR`, `SYSTEM`), generados al arrancar y guardados en un archivo local ignorado por git. La identidad de quien decide sale siempre del token. | Ver `SEGURIDAD.md`. No es autenticación real. |
| S-09 | Docker puede no estar disponible en la máquina de trabajo. | **Decisión del autor:** si el daemon no inicia, el perfil `full` queda configurado y documentado, marcado como "no ejecutado". | Se indica en `ESCENARIOS.md` y en el informe final. |
